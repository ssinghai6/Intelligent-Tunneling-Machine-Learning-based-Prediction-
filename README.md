# Intelligent Tunneling: Machine Learning-based Prediction

This project focuses on predicting stress, elastic, and plastic strain fields around a cavity during tunneling operations using machine learning. The goal is to bypass traditional simulations by training ML models to generate these outputs based on various inputs like position, cavity geometry, and soil parameters.

## Description

The primary objective of this research is to develop a surrogate model using machine learning techniques to rapidly predict ground responses (stress, strain) due to subsurface excavation, such as that performed by a tunneling robot. By learning from data generated by physics-based simulations, the model can provide real-time predictions, significantly speeding up the analysis process compared to running new simulations for every change in parameters.

The models in this repository are trained on inputs including:
- Position of the cavity
- Geometry of the tunneling robot (modeled as a cavity)
- Soil parameters or sensor data (e.g., pressure-volume curve)

## Project Structure

The repository contains several Jupyter notebooks, each serving a specific purpose in the analysis:

-   `ANN.ipynb`: Implements an Artificial Neural Network (ANN) for prediction.
-   `Random_forest_final.ipynb`: Uses a Random Forest model for prediction.
-   `Random_forest_Stress_contour.ipynb`: Focuses on generating stress contour plots from the Random Forest model's output.
-   `RNN_FINAL_6para.ipynb`: Implements a Recurrent Neural Network (RNN) with 6 parameters.
-   `RNN_parametrized_Pdistri_Reverse.ipynb`: An RNN model for predicting pressure distribution.
-   `data_2_image.ipynb`: Notebook for converting raw data into image-based formats for model training.
-   `Pecentile_plot.ipynb`: Contains code for generating percentile plots for data analysis.
-   `I1.ipynb` & `I2.ipynb`: Additional analysis or modeling notebooks.

The `Figures/` directory contains plots and images generated from these notebooks.
